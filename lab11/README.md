# Лабораторная работа №11 — DSA (FIPS 186)

Программа подписывает произвольные файлы алгоритмом DSA, применяя SHA-256. Подпись `(r,s)` хранится в отдельном JSON-файле, проверка выполняется по открытому ключу.

```bash
python dsa_fips186.py keygen
python dsa_fips186.py sign документ.pdf
python dsa_fips186.py verify документ.pdf документ.pdf.sig
```

Для ключей доступны `--private` и `--public`; команды `sign` и `verify` принимают `--key`, команда `sign` — `--out`. По умолчанию создаются `private.json`, `public.json` и подпись с суффиксом `.sig`.

Реализация следует стандартным уравнениям DSA, но использует укороченные параметры `L=256`, `N=160` ради быстрого учебного запуска и упрощённую генерацию параметров. Это не валидированный модуль FIPS 186 и не предназначено для реальной защиты.
