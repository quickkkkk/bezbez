# Лабораторная работа №13 — слепая подпись и анонимное голосование

## Подробная защита

В [blind_voting.py](blind_voting.py) серверная и клиентская части разделены классами `VotingServer` и `VotingClient`. Сервер регистрирует допустимые ID, генерирует RSA-пару и разрешает каждому ID получить одну подпись. Клиент выбирает один из вариантов «Да», «Нет», «Воздержался», создаёт случайный серийный номер бюллетеня и вычисляет `m=SHA256(версия|серийный_номер|вариант) mod n`.

Для слепой подписи клиент выбирает случайный обратимый множитель `r`, вычисляет `m'=m·r^e mod n` и отправляет серверу ID вместе с `m'`. Сервер применяет закрытую степень и возвращает `s'=m'^d mod n`. Клиент снимает ослепление: `s=s'·r⁻¹ mod n`. По RSA `s^e≡m mod n`, но сервер при выдаче подписи не видел открытый `m` и не знает выбранный вариант.

Клиент передаёт бюллетень и обычную подпись. Сервер проверяет RSA-равенство для хеша, допустимость варианта и уникальность серийного номера, после чего увеличивает счётчик выбранного ответа. ID используется только при выдаче, а бюллетень при приёме не содержит ID. Консоль показывает числа RSA, слепые значения, подпись и итоговые счётчики; закрытые значения выводятся только для учебной демонстрации.

Демонстрация моделирует все роли в одном процессе, а RSA не использует стандартизованное дополнение и не защищён сетевым каналом. Она иллюстрирует сокрытие выбора от подписывающего сервера, но не защищает от сговора, повторных регистраций, принуждения, отказа в обслуживании или корреляции времени. Для реального голосования необходимы проверяемая регистрация избирателей, защищённый канал, аудит, криптографические доказательства и независимая оценка реализации.

Запуск: `python blind_voting.py`. Программа спросит список зарегистрированных ID и голоса каждого участника.

## Краткая защита

Клиент ослепляет хеш бюллетеня случайным множителем и получает RSA-подпись сервера, не раскрывая свой выбор. После снятия ослепления подпись проверяется на бюллетене. Сервер принимает только допустимые варианты и уникальные серийные номера, затем считает голоса.
