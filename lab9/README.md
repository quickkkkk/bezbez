# Лабораторная работа №9 — электронная подпись Эль-Гамаля

Программа подписывает произвольный файл по схеме Эль-Гамаля. Для хеширования применяется SHA-256. Подпись хранится отдельно в JSON-файле.

```bash
python elgamal_signature.py keygen
python elgamal_signature.py sign документ.pdf
python elgamal_signature.py verify документ.pdf документ.pdf.sig
```

`keygen` создаёт `private.json` и `public.json`; размер простого модуля по умолчанию — 512 бит. Файлы ключей можно выбрать параметрами `--private` и `--public`. Для `sign` можно задать закрытый ключ через `--key` и имя подписи через `--out`. Для `verify` указываются файл, файл подписи и открытый ключ через `--key`.

Формулы схемы: `y = g^x mod p`; для хеша `m` выбирается случайное `k`, взаимно простое с `p−1`; `r = g^k mod p`, `s = k⁻¹(m−xr) mod (p−1)`. Проверка принимает подпись, если `y^r r^s mod p = g^m mod p`. Для каждого документа используется новый случайный `k`.

Это самостоятельная учебная реализация с вероятностной проверкой простоты. Размер ключа по умолчанию рассчитан на демонстрацию, а код не прошёл криптографическую сертификацию; не используйте его для защиты реальных данных.
