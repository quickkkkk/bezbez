# Защита лабораторной работы №9 — подпись Эль-Гамаля

## Подробный вариант

Программа `elgamal_signature.py` хеширует полный файл алгоритмом SHA-256 и подписывает полученное целое по схеме Эль-Гамаля. Параметры открытого ключа — простой модуль `p`, элемент `g` и `y=g^x mod p`; секретом является `x`. Для подписи выбирается новый случайный `k`, взаимно простой с `p−1`; вычисляются `r=g^k mod p` и `s=k⁻¹(h−xr) mod (p−1)`. Подписью служит пара `(r,s)`.

Проверяющий вычисляет хеш того же файла и проверяет равенство `y^r · r^s ≡ g^h (mod p)`. Если файл изменён, хеш меняется и проверка не проходит. Подпись хранится отдельно в JSON, а команда `keygen` формирует ключи. Команды `sign` и `verify` принимают путь к исходному файлу и ключам. Алгоритм генерации числа `k` использует системный источник случайности; повторное использование `k` может раскрыть секретный ключ, поэтому для каждого документа значение выбирается заново.

SHA-256 сильнее минимально требуемого MD5. Реализация учебная, параметры меньше современных производственных и протокол не сертифицирован; для настоящей подписи нужна проверенная библиотека.

## Краткий вариант

Программа подписывает SHA-256 хеш файла по Эль-Гамалю закрытым ключом и сохраняет пару `(r,s)`. Проверка открытым ключом устанавливает, что подпись создана владельцем секрета и файл после подписания не изменился.
