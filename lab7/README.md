# Лабораторная работа №7 — XOR-шифрование Вернама

## Подробная защита

Программа [vernam_file.py](vernam_file.py) обрабатывает произвольные бинарные файлы операцией XOR. Для каждого байта вычисляется `Cᵢ=Mᵢ XOR Kᵢ`; та же операция расшифровывает данные, поскольку `A XOR B XOR B=A`. Соль и длина файла записываются в заголовок контейнера.

По требованию ключевой материал может формироваться схемой Диффи–Хеллмана: стороны получают общий `K=g^(X_A X_B) mod p`, затем SHA-256 с солью и счётчиком расширяет его до потока байтов. В меню ключи и параметры для демонстрации генерируются автоматически; секреты сохраняются в `.key.json`, чтобы затем расшифровать файл. Запуск: `python vernam_file.py encrypt input.bin`, затем `python vernam_file.py decrypt input.bin.vernam`.

Строгий одноразовый блокнот требует равномерно случайный ключ длины файла, который используется ровно один раз и передаётся по защищённому каналу. Короткий секрет Диффи–Хеллмана, расширенный хеш-функцией, является учебным XOR-поточным шифром, но не информационно-теоретически стойким одноразовым блокнотом. Не используйте демонстрационное хранение ключей для реальных секретных данных.

## Краткая защита

Шифрование и расшифрование — одна и та же операция XOR. Общий ключ получают через Диффи–Хеллмана; соль и счётчик вместе с SHA-256 дают поток байтов требуемой длины. Это демонстрационный потоковый вариант, а не строгий одноразовый блокнот.
