# Лабораторная работа №6 — RSA-шифрование файлов

## Подробная защита

В [rsa.py](rsa.py) реализованы генерация ключей и блочное шифрование файлов. Для различных простых `p` и `q` вычисляются `n=pq` и `φ(n)=(p−1)(q−1)`. Закрытая степень `d` взаимно проста с `φ(n)`, открытая степень `c=d⁻¹ mod φ(n)`. Шифрование выполняется как `E=M^d mod n`, расшифрование — `M=E^c mod n`.

Файл читается в двоичном режиме, разбивается на блоки, которые гарантированно меньше `n`, переводится в целые числа и обратно. Для каждого блока записываются его исходная длина и зашифрованное число фиксированной ширины. Тем самым сохраняется точное содержимое файла, включая нулевые байты. Параметры можно ввести или сгенерировать; генератор использует проверку Миллера–Рабина. Python выполняет операции с целыми числами произвольной точности.

Запуск: `python rsa.py`, далее меню вводит параметры и пути. Программа в папке содержит демонстрационные файлы. Учебное «голое» RSA без паддинга не обеспечивает современную стойкость и не должно использоваться для защиты реальных файлов; производственные системы применяют гибридное шифрование и стандартизованные схемы.

## Краткая защита

RSA вычисляет открытый и закрытый показатели через простые множители модуля `n=pq`. Файл делится на блоки меньше `n`; каждый блок возводится в степень по модулю, а при расшифровании операция обращается. Формат сохраняет размер блоков.
