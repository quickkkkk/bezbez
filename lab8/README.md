# Лабораторная работа №8 — электронная подпись RSA

## Подробная защита

В [rsa_signature.py](rsa_signature.py) реализованы создание ключей, подписание файла и проверка подписи. Генерируются простые `p,q`, модуль `n=pq`, открытая степень `e=65537` и закрытая `d=e⁻¹ mod ((p−1)(q−1))`. Перед подписью вычисляется SHA-256 от всех байтов файла и переводится в целое число `h`. Подписывающая сторона вычисляет `s=h^d mod n`; проверяющая вычисляет `s^e mod n` и сравнивает с хешем заново прочитанного файла.

Для учебной работы используются два простых множителя по 512 бит, поэтому модуль имеет около 1024 бит и значительно больше 256-битного результата SHA-256. Подпись хранится отдельно в JSON вместе с названием алгоритма и хешем. Изменение файла приводит к несовпадению при проверке. Интерфейс командный: `keygen`, `sign`, `verify`; параметры ключей можно задавать путями.

Запуск: `python rsa_signature.py keygen`, `python rsa_signature.py sign file`, `python rsa_signature.py verify file file.sig`. Это учебная «сырая» RSA-подпись без PSS/PKCS#1 padding и без сертификации. Для реальных подписей нужно использовать стандартизованную криптографическую библиотеку и проверенную схему.

## Краткая защита

Файл хешируется SHA-256. Закрытая степень RSA превращает хеш в подпись; открытая степень восстанавливает значение, которое сравнивается с новым хешем. Любое изменение файла обнаруживается проверкой.
