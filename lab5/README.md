# Лабораторная работа №5 — шифрование Эль-Гамаля

## Подробная защита

В [elgamal_file.py](elgamal_file.py) реализовано шифрование байтов файла по схеме Эль-Гамаля. Параметры — простой модуль `p`, основание `g`, закрытый ключ `x` и открытый ключ `y=g^x mod p`. Для каждого байта `m` независимо выбирается случайное `k`; формируется пара `c₁=g^k mod p`, `c₂=m·y^k mod p`. Расшифрование вычисляет `m=c₂·(c₁^x)⁻¹ mod p`.

В контейнер записываются маркер формата, ширина чисел, модуль, длина файла и пары блоков фиксированной ширины. Каждый исходный байт кодируется отдельным элементом группы, что упрощает обратное восстановление любых бинарных данных, включая пустые файлы. При автоматическом режиме генерируется безопасный простой модуль `p=2q+1`, после чего первообразный корень выбирается проверками степеней без факторизации большого числа `p−1`. Также генерируется закрытый параметр и случайный `k` для каждого байта. Ключевой JSON-файл содержит закрытый секрет для последующего восстановления; его нужно хранить отдельно.

Пример: `python elgamal_file.py encrypt photo.jpg`; программа предложит ввести `p,g,C₂` или сгенерирует параметры. Затем выполните `python elgamal_file.py decrypt photo.jpg.elgamal`. Параметры также можно передать флагами `--p`, `--g`, `--x`. Это учебная побайтовая реализация: она не добавляет аутентификацию и медленнее промышленных гибридных схем; не применяйте её для реальной защиты.

## Краткая защита

Для каждого байта алгоритм создаёт случайную пару `c₁,c₂`, связанную с открытым ключом получателя. Закрытый показатель позволяет восстановить байт. Случайный параметр меняется для каждого блока, а бинарный контейнер хранит длину и пары чисел.
