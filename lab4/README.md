# Лабораторная работа №4 — трёхпроходный шифр Шамира

## Подробная защита

Программа [shamir_file.py](shamir_file.py) шифрует файлы в бинарном режиме. Для простого `p` каждый участник выбирает показатель `C`, взаимно простой с `p−1`, и вычисляет обратный показатель `D=C⁻¹ mod (p−1)`. Шифрование выполняется тремя проходами: отправитель применяет `C_A`, получатель применяет `C_B`, отправитель снимает свой слой `D_A`, получатель снимает оставшийся слой `D_B`. Благодаря свойству степеней по модулю результат равен исходному байту.

В программе обе стороны представлены одним запуском: каждый байт проходит две степени шифрования, а расшифровка применяет оба обратных показателя. Заголовок контейнера хранит маркер формата, модуль и длину исходного потока; значения каждого байта сериализуются фиксированной шириной. Это сохраняет нулевые байты, длину и произвольное содержимое файла. Параметры можно передать аргументами; если они не заданы, программа генерирует их, а закрытые `D_A`, `D_B` сохраняет в отдельном JSON-файле рядом с шифротекстом.

Пример: `python shamir_file.py encrypt input.bin`; программа предложит ввести параметры либо сгенерирует их. Затем выполните `python shamir_file.py decrypt input.bin.shamir`. Учебный режим сохраняет ключевой файл открытым рядом с контейнером для удобства демонстрации; его необходимо хранить отдельно и защищать. Сам по себе протокол не обеспечивает целостность файла.

## Краткая защита

Шифр Шамира использует два взаимно простых с `p−1` показателя. Стороны последовательно накладывают степени и снимают собственные слои обратными показателями. Формат хранит длину и бинарные блоки, поэтому поддерживаются любые файлы.
