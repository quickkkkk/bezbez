# Защита лабораторной работы №10 — ГОСТ Р 34.10-94

## Подробный вариант

В `gost94.py` реализована учебная схема подписи ГОСТ Р 34.10-94. Генерируются простые параметры `q` и `p=bq+1`, затем элемент `a` порядка `q` в мультипликативной группе по модулю `p`. Закрытый ключ `x` выбирается из диапазона `1..q−1`, открытый ключ вычисляется как `y=a^x mod p`.

Сначала вычисляется SHA-256 файла и приводится к диапазону порядка `q` (нулевой результат заменяется единицей). Для подписи выбирается случайный секретный `k`; вычисляются `r=(a^k mod p) mod q` и `s=(x·r+k·h) mod q`. Значения, равные нулю, отбрасываются. Проверяющий вычисляет `v=h⁻¹ mod q`, `z₁=s·v mod q`, `z₂=−r·v mod q`, затем сравнивает `(a^z₁·y^z₂ mod p) mod q` с `r`.

Хеш SHA-256 обеспечивает требование по стойкости хеширования, подпись сохраняется в отдельном JSON-файле. Имеются команды генерации ключей, подписания и проверки файлов. Реализация использует учебные сокращённые параметры и случайные параметры без сертификации, поэтому не предназначена для реальной защиты.

## Краткий вариант

Схема ГОСТ строит подпись `(r,s)` из хеша файла, закрытого ключа и случайного `k`. Открытый ключ и хеш позволяют проверить равенство по модулю параметров `p,q`; изменение файла приводит к отказу проверки.
