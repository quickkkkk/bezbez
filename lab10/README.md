# Лабораторная работа №10 — ГОСТ Р 34.10-94

Учебная программа цифровой подписи файлов. Использует SHA-256, создаёт отдельную подпись JSON и проверяет её открытым ключом. Реализована схема ГОСТ Р 34.10-94: параметры `p, q, a`, закрытый ключ `x`, открытый `y=a^x mod p`, подпись `(r,s)`.

```bash
python gost94.py keygen
python gost94.py sign документ.pdf
python gost94.py verify документ.pdf документ.pdf.sig
```

Ключи можно задать через `--private` и `--public`, при подписании — `--key` и `--out`, при проверке — `--key`. Хешируется исходное содержимое файла. Подмена файла обнаруживается проверкой подписи.

Параметры генерируются случайно для удобства лабораторной; это не сертифицированная реализация и её нельзя применять для защиты реальных данных. Проверка простоты Миллера—Рабина вероятностная.
