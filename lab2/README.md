# Лабораторная работа №2 — дискретный логарифм

## Подробная защита

Функция `baby_step_giant_step(a, y, p)` в [discrete_log_lab2.py](discrete_log_lab2.py) ищет `x`, удовлетворяющий `a^x ≡ y (mod p)`. При `m = ceil(sqrt(p−1))` сначала сохраняются значения `a^j mod p` для `0 ≤ j < m`. Затем вычисляются «гигантские шаги» `y·a^(−im) mod p`; совпадение с таблицей даёт `x=im+j`. Обратный элемент находится расширенным возведением по модулю, а найденный ответ повторно проверяется.

Таблица содержит порядка `sqrt(p)` элементов, и число giant-шагов также порядка `sqrt(p)`. Поэтому время и память составляют `O(√p)`. Это стандартная трудоёмкость baby-step giant-step (в условии она обозначена как `O(p log p)`, но описание шага младенца/великана соответствует именно квадратному корню). Модуль проверяется тестом Ферма; отсутствие решения обозначается `None`. Генератор строит задачу с известным секретным показателем, а меню поддерживает ручной ввод и генерацию.

Запуск: `python discrete_log_lab2.py`. Это учебный алгоритм: при большом `p` таблица быстро становится слишком большой.

## Краткая защита

Алгоритм разбивает показатель на два шага размера около `√p`: заранее строит таблицу малых степеней основания и ищет совпадение среди обратных больших шагов. Решение перепроверяется подстановкой. Трудоёмкость и память — `O(√p)`.
