# Лабораторная работа №3 — общий ключ Диффи–Хеллмана

## Подробная защита

В [diffie_hellman_lab3.py](diffie_hellman_lab3.py) реализован обмен двумя участниками. Участники выбирают секреты `X₁`, `X₂`, публикуют `A=g^X₁ mod p` и `B=g^X₂ mod p`. Первый вычисляет `K₁=B^X₁ mod p`, второй — `K₂=A^X₂ mod p`; оба результата равны `g^(X₁X₂) mod p`. Функция возвращает параметры, оба открытых значения и оба варианта ключа, а свойство результата проверяет их совпадение.

Для автоматического режима выбирается вероятно простое `p`, находится первообразный корень `g` и генерируются секретные показатели. `is_primitive_root` проверяет порядок элемента через простые делители `p−1`. В ручном режиме пользователь задаёт `p`, `g`, `X₁`, `X₂`. Арифметика Python сохраняет точность больших целых.

Запуск: `python diffie_hellman_lab3.py`. Протокол сам по себе не аутентифицирует участников и уязвим к атаке посредника без дополнительной аутентификации; малые демонстрационные параметры не обеспечивают реальную стойкость.

## Краткая защита

Участники обмениваются открытыми степенями `g^X mod p`, затем каждый возводит полученное значение в свой секретный показатель. Они получают одинаковый ключ `g^(X₁X₂) mod p`. Программа поддерживает ручные и автоматически сгенерированные параметры.
