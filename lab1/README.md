# Лабораторная работа №1 — базовая криптографическая библиотека

## Подробная защита

В папке находится [crypto_library.py](crypto_library.py) с тремя основными функциями. `mod_pow(a, n, p)` вычисляет `aⁿ mod p` двоичным методом: показатель последовательно делится на два, при каждом бите результат умножается на текущую степень основания. Поэтому вместо `n` умножений выполняется логарифмическое число шагов. Встроенные целые числа Python имеют произвольную точность, поэтому вычисления не ограничены размером машинного слова.

`fermat_primality_test(n, rounds)` реализует вероятностный тест Ферма. Для каждого случайного основания проверяется взаимная простота с `n` и сравнение `a^(n−1) mod n` с единицей. Если условие нарушено, число составное; если все раунды пройдены, число считается вероятно простым. Тест может пропустить числа Кармайкла, поэтому вероятность ошибки уменьшается увеличением числа раундов, но математическое доказательство простоты он не даёт.

`extended_gcd(a, b)` возвращает `(g, x, y)`, где `g = НОД(a,b)` и `ax+by=g`. Расширенный алгоритм Евклида одновременно с остатками обновляет коэффициенты Безу; знаки входных чисел обработаны отдельно. `generate_numbers` создаёт произвольные либо вероятно простые числа; `read_numbers` обеспечивает ввод с клавиатуры. Запуск `python crypto_library.py` показывает меню этих режимов и выводит проверку равенства Безу.

Для демонстрации запустите `python crypto_library.py`. В файле также есть функции, пригодные для импорта из следующих лабораторных. Это учебный код: тест Ферма и небольшие случайные числа не предназначены для генерации производственных ключей.

## Краткая защита

Библиотека реализует быстрое возведение в степень по модулю, вероятностный тест простоты Ферма и расширенный алгоритм Евклида. Последний находит НОД и коэффициенты Безу. Числа можно ввести или сгенерировать, в том числе с проверкой вероятной простоты. Python поддерживает целые числа произвольной длины.
