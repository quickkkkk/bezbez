# Лабораторная работа №12 — ментальный покер

Запуск графического приложения:

```bash
python mental_poker.py
```

Приложение раздаёт каждому игроку две карты и выкладывает пять общих карт Texas Hold'em. Количество игроков задаётся в диапазоне 2–10.

## Идея протокола и честность

Колода представляется числами 1–52. Каждый участник выбирает секретный показатель `e`, взаимно простой с `p−1` для простого `p`, и публикует слой `E(x)=x^e mod p`; обратный показатель `d=e⁻¹ mod (p−1)` сохраняет в секрете. Участники последовательно шифруют всю колоду и независимо перемешивают её. Карты передаются как значения со всеми слоями шифрования. Чтобы открыть выбранную карту, каждый участник снимает только собственный слой (`x=x^d mod p`), и в конце остаётся номер исходной карты. Перестановка неизвестна одному участнику, а чужие слои он снять не может. При корректном случайном выборе секретов и честном перемешивании это затрудняет узнавание и подмену карт одним участником; после открытия все могут сверить уникальность 52 исходных карт.

## Ограничения демонстрации

Приложение имитирует протокол в одном процессе и показывает все руки на одном экране; оно не обеспечивает приватность между игроками, сетевую проверяемость перемешивания, доказательства корректного шифрования или защиту от сговора/отказа участника. Поэтому обоснование выше относится к идеализированному протоколу с отдельными участниками и обменом сообщений, а GUI служит демонстрацией раздачи, не полноценной криптографической системой. Для настоящего ментального покера необходимы проверяемые перемешивания и протоколы доказательств с проверкой сохранения колоды.
