# Лабораторные работы по криптографии

Все 13 лабораторных представлены отдельными папками `lab1`–`lab13`. По результатам просмотра проекта до изменений были готовы №1–3, №6 и №9–12; отсутствовали №4, №5, №7, №8 и №13. Недостающие работы добавлены на Python.

В каждой папке находится программа и защита: подробное объяснение, затем короткий вариант. Для №9–12 тексты защит лежат в `ЗАЩИТА.md` рядом с README запуска.

| № | Тема | Основной файл |
|---|---|---|
| 1 | Базовая криптографическая библиотека | `lab1/crypto_library.py` |
| 2 | Дискретный логарифм, BSGS | `lab2/discrete_log_lab2.py` |
| 3 | Диффи–Хеллман | `lab3/diffie_hellman_lab3.py` |
| 4 | Шифр Шамира для файлов | `lab4/shamir_file.py` |
| 5 | Шифрование Эль-Гамаля файлов | `lab5/elgamal_file.py` |
| 6 | RSA-шифрование файлов | `lab6/rsa.py` |
| 7 | XOR-шифрование Вернама с ключом Диффи–Хеллмана | `lab7/vernam_file.py` |
| 8 | RSA-подпись файлов | `lab8/rsa_signature.py` |
| 9 | Подпись Эль-Гамаля | `lab9/elgamal_signature.py` |
| 10 | ГОСТ Р 34.10-94 | `lab10/gost94.py` |
| 11 | DSA / FIPS 186 | `lab11/dsa_fips186.py` |
| 12 | Ментальный покер, Texas Hold’em GUI | `lab12/mental_poker.py` |
| 13 | Слепая RSA-подпись и голосование | `lab13/blind_voting.py` |

Реализации учебные. Особенно для подписей, блочного RSA и протоколов без сетевой аутентификации не следует трактовать демонстрационный код как средство защиты реальных данных.
